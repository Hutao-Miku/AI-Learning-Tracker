# AI 学习追踪 · B站无感出题 浏览器插件

随项目根目录 `browser-extension/` 提供的 Microsoft Edge（Chromium 内核）插件，Manifest V3 标准。
**核心特性：必须开启「学习模式」才会自动出题；关闭时看任何视频（含娱乐视频）都不会弹窗。**
B站页面内注入一个可拖拽的「学习追踪」悬浮窗，开关与工具栏弹窗完全双向同步。

## 文件夹结构

```
browser-extension/
├── manifest.json   # 插件清单（MV3），含 action 弹出面板 + 悬浮窗注入声明
├── content.js      # 注入 B站视频页：悬浮窗 + 学习模式门控 + 抓取出题
├── background.js   # Service Worker，把内容 POST 到本地后端
├── popup.html      # 点击插件图标弹出的「学习模式」面板（含「显示悬浮窗」按钮）
├── popup.js        # 弹窗逻辑，读写 chrome.storage.local，可向页面发「显示悬浮窗」指令
├── tests/
│   └── gate.test.js # node 模拟开关自检脚本（仅供开发验证，不影响插件加载）
└── README.md       # 本说明
```

## 工作流

1. 你在 Edge 打开 `https://www.bilibili.com/video/BVxxxx` 并开始观看。
2. **前提**：B站页面右上角会出现「学习追踪」悬浮窗，把里面的「学习模式」开关拨到 **开**。
   （也可点击浏览器右上角插件图标，在弹出面板里开启；两者完全同步。）关闭时 content.js 直接 return，不监听、不抓取、不调后端、不弹窗。
3. 学习模式开启时，插件监听 `<video>` 的 `timeupdate` 事件，进度 ≥ 95% 或播放结束时触发一次。
4. 抓取 **BV 号、标题、AI 视频总结**（若页面没有 AI 总结，则依次兜底：视频简介 → 热门弹幕 → 评论）。
5. `background.js` 通过 `fetch` POST 到 `http://localhost:8080/api/ai/generateFromBili`。
6. 后端按 BV 号去重、自动建立「B站自动追踪」课程、调用智谱 AI 生成题目入库，返回「出题成功」。
7. 页面右上角弹出蓝色通知「AI 已出好题 🎉，点击去作答 →」，点击即打开 `http://localhost:5173/quiz` 作答。

> 注意：必须先启动本地后端（8080）与前端（5173），再打开 B站视频，否则插件会提示通信失败。

## 一、Edge 加载插件详细教程（从 0 开始）

### 第 1 步：打开扩展管理页
在 Edge 地址栏输入并回车：
```
edge://extensions/
```
（也可点击右上角 `⋯` → **扩展** → **管理扩展**）

### 第 2 步：开启「开发人员模式」
页面左下角（部分版本在左上角）有一个 **“开发人员模式”** 开关，把它拨到 **开（蓝色）**。
开启后，页面顶部会出现一排按钮：`加载解压缩的扩展`、`打包扩展`、`导出`。

### 第 3 步：加载解压缩的扩展
1. 点击 **“加载解压缩的扩展”** 按钮。
2. 在弹出的文件选择框中，选中本项目的 **`browser-extension` 文件夹**（注意：选文件夹本身，不要只选里面的某个文件）。
   - 正确示例：选中 `E:\HatsuneMIKU\Documents\WorkBuddy\Work\browser-extension`
3. 点击「选择文件夹」。

加载成功后，扩展列表中会出现 **“AI 学习追踪 · B站无感出题”**，并带有一个自动生成的彩色图标。

### 第 4 步：确认权限（如有弹窗）
首次加载一般不会弹窗。若 Edge 提示「需要权限」，点击「允许」即可。
本插件申请的权限说明：
- `storage`：保存「学习模式」开关、悬浮窗位置、显隐状态（核心）。
- `activeTab` / `scripting`：注入与通信所需。
- `notifications`：预留的通知能力。
- 主机权限：`*://*.bilibili.com/video/*`（注入脚本）、`http://localhost:8080/*`、`http://localhost:5173/*`（访问本地前后端）。

### 第 5 步：开启「学习模式」并开始使用
1. 确保后端与前端已运行（见下方「本地服务」）。
2. 打开一个 B站**学习**视频页，页面右上角会出现「学习追踪」悬浮窗。
3. 把悬浮窗里的「学习模式」开关拨到 **开**（或点击右上角插件图标，在弹出面板里开启）。
4. 正常观看，进度到 95% 左右（或播完），稍候页面右上角出现蓝色通知即代表出题成功。

## 二、改了插件代码后，如何「刷新/重载」插件（重要）

你修改了 `content.js` / `popup.js` / `manifest.json` / `background.js` 之后，**必须重新加载插件**才能让改动生效（Edge 不会自动热更新）：

1. 打开 `edge://extensions/`。
2. 找到本插件的卡片。
3. 点击卡片上的 **“重新加载”** 按钮（图标是一个 ↻ 圆形箭头，鼠标悬停显示「重新加载」）。
   - 或者：直接按快捷键 **`Ctrl + R`**（焦点在该卡片上时）也能重载。
4. 若改了 `manifest.json`（如新增了 `action`），重载后建议先把插件**移除**再「加载解压缩的扩展」一次，避免清单变更残留。

> 排错：若卡片上出现红色错误文字（如 manifest 语法错误），修正文件后点「重新加载」即可，无需重新选文件夹。

## 三、悬浮窗拖拽使用指南

插件会在每个 B站视频页注入一个 **「学习追踪」悬浮窗**，位于页面右上角：

```
┌─────────────────────┐
│ 学习追踪        [×] │  ← 标题栏（拖拽区）
│ 学习模式   [开关]   │  ← 学习模式开关（Switch）
└─────────────────────┘
```

### 1. 开关与状态同步（双向绑定）
- 悬浮窗里的「学习模式」开关，和浏览器右上角插件图标弹出的面板开关，**读写的是同一个 `chrome.storage.local` 键**，完全双向同步：
  - 在悬浮窗里拨开关 → popup 面板里的开关立刻跟着变；反之亦然。
  - 任意一处改变，content.js 都会实时感知（`storage.onChanged`），立即开始/停止监听。
- **视觉反馈**：
  - 关闭：悬浮窗**置灰 + 半透明**（灰色），表示未在追踪。
  - 开启：悬浮窗标题栏**高亮蓝色**，表示正在追踪，看到 95% 会自动出题。

### 2. 拖拽移动
- 用鼠标**按住悬浮窗标题栏**（即「学习追踪」那一行，不要按开关或 ×），拖动到任意位置。
- **位置自动持久化**：松手后，悬浮窗的 `{ top, left }` 会写入 `chrome.storage.local` 的 `widgetPos`；下次刷新页面 / 重开浏览器，悬浮窗会出现在**完全相同的位置**。
- **防干扰细节**：
  - 拖动时调用 `e.preventDefault()` 并临时禁用页面文字选中（`user-select:none`），所以**不会误选页面文字**。
  - 拖拽只在标题栏生效；**开关和 × 按钮被排除**，所以拖拽不会误触开关、也不会触发点击。
  - 内置 3px 移动阈值（防抖）：只有真正移动超过阈值才算拖拽，避免「点一下」被误判为拖拽。

### 3. 隐藏与恢复
- 点击悬浮窗右上角的 **×**：悬浮窗只是 `display:none` 隐藏，**不会销毁**（监听器仍在，学习模式继续生效）。
- 想再显示它：点击浏览器右上角**插件图标**，在弹出面板里点 **「显示悬浮窗」** 按钮：
  - 该按钮会把 `widgetHidden` 置为 false，并向当前 B站视频页的 content.js 发送 `SHOW_WIDGET` 指令，悬浮窗立即重新出现。
  - 隐藏状态同样持久化：刷新页面后若之前关掉了，仍保持隐藏，需再次点「显示悬浮窗」恢复。
- 若提示「当前不是 B站视频页」，请先切到一个 B站视频页再点。

### 4. 不被遮挡
- 悬浮窗 `z-index: 2147483647`（最高层），不会被 B站弹幕、侧边栏、评论区遮挡。

## 四、本地服务如何启动（回忆）

项目根目录有 `start.bat` / `start.vbs`：
- 双击 `start.vbs`（后台静默启动，推荐）或 `start.bat`（前台两个黑框）。
- 它会分别启动后端（8080）与前端（5173）。
- 启动完成后浏览器会自动打开 `http://localhost:5173`。

若后端未启动，插件会弹出红色提示「后端连接失败，请确认后端已启动且端口未被占用」。

## 五、如何查看插件报错日志（排错）

### 方式 A：查看 Service Worker（background.js）日志
1. 打开 `edge://extensions/`。
2. 找到本插件卡片，点击 **“详细信息”**（或卡片上的拓展箭头）。
3. 在详情页找到 **“检查视图：Service Worker”**，点击它。
4. 弹出的 DevTools Console 里能看到 `background.js` 的日志，例如：
   ```
   [AI追踪-background] 收到出题请求: BV1xx 来源= 视频简介
   [AI追踪-background] 后端返回: 成功
   ```
   若后端地址不可达，会看到 `请求异常: TypeError: Failed to fetch`。

### 方式 B：查看 content.js（页面内）日志
1. 在 B站视频页按 `F12` 打开开发者工具。
2. 切到 **Console** 面板，能看到来自本扩展的日志：
   - 学习模式关闭：`[AI追踪] 学习模式未开启，本页不监听视频、不出题`
   - 学习模式开启：`[AI追踪] 学习模式已开启，准备监听视频进度` → `[AI追踪] 已挂载到播放器，监听进度`
   - 触发出题：`[AI追踪] 触发出题：...`、`[AI追踪] 出题失败：...` 等。

### 方式 C：查看悬浮窗 / popup 面板
- 悬浮窗实时反映学习模式开关状态（置灰 / 蓝色高亮）。
- 点击插件图标，面板会显示「当前：已开启 / 未开启」，并可点「显示悬浮窗」恢复隐藏的悬浮窗。

## 七、常见问题排错

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 无论如何都不弹窗 | 「学习模式」未开启 | 在悬浮窗或 popup 里把开关拨到开 |
| 看娱乐视频也弹窗 | 学习模式被误开 | 关闭开关；关闭状态下绝对不弹 |
| 悬浮窗没出现 | 之前点 × 关掉了，或当前不是视频页 | 点插件图标 →「显示悬浮窗」；确认在 `*://*.bilibili.com/video/*` 页面 |
| 悬浮窗位置变了 | 拖动后已持久化 | 正常；再拖动到喜欢的位置即可，会记住 |
| 拖拽时选中了页面文字 | 理论上已禁用；若仍发生 | 重新加载插件；拖动请只按住标题栏 |
| 没有出现通知 | 视频进度没到 95% / 播放器未加载 | 等待进度、确认 `<video>` 已出现；看 Console 是否有「已挂载到播放器」 |
| 红色「后端连接失败…」 | 后端 8080 没启动 | 运行 `start.vbs`；确认 `http://localhost:8080/api/hello` 可访问 |
| 「未能抓取到任何视频内容」 | 页面简介/总结/弹幕/评论都为空 | B站部分视频无简介；可先确认页面有文字内容再观看 |
| 后端报「未配置智谱 API Key」 | 环境变量 `ZHIPU_API_KEY` 未设置 | 启动后端前 `set ZHIPU_API_KEY=你的key` 或写入系统环境变量 |
| 同一视频重复弹通知 | 已按 BV 号幂等去重 | 后端对同 BV 号复用已生成题目，不会重复消耗额度 |
| 改了插件代码没生效 | 没重新加载 | 在 `edge://extensions/` 点本插件的「重新加载」按钮 |

## 八、后端对接说明（给开发者）

- 接收接口：`POST http://localhost:8080/api/ai/generateFromBili`
- 请求体：
  ```json
  {
    "bvid": "BV1xx411c7mD",
    "title": "视频标题",
    "text": "抓到的素材文本（AI总结/简介/弹幕/评论）",
    "source": "AI视频总结 | 视频简介 | 热门弹幕 | 评论"
  }
  ```
- 成功响应：`{ "code": 200, "message": "出题成功", "data": [ ...题目... ] }`
- 已配置 CORS（允许 `localhost` / `chrome-extension://` / `null` 源），无需额外处理跨域。
